OweeCapture

Graba la pantalla, haz capturas, transmite en directo y termina tus vídeos. Hecha para quien enseña y crea contenido en Linux. Record the screen, take screenshots, stream live and finish your videos. Made for people who teach and create content on Linux.

Instalar y actualizarInstall and update

Elige según tu distribución. En todas se comprueba con oweecapture --version. Pick the one for your distribution. In all of them you can check with oweecapture --version.

Debian, Ubuntu, Kubuntu, KDE neon, Mint, DeepinDebian, Ubuntu, Kubuntu, KDE neon, Mint, Deepin

La opción más fácil: descarga el .deb e instálalo. Desde ese momento las versiones nuevas llegan con apt upgrade.The easiest option: download the .deb and install it. From then on new versions arrive with apt upgrade.

sudo apt install ./oweecapture_@VERSION@_all.deb

O añade el repositorio (firmado) y se instala y actualiza como cualquier otro programa:Or add the (signed) repository and it installs and updates like any other program:

sudo install -d /usr/share/keyrings
curl -fsSL https://oweeme.github.io/oweecapture/oweecapture.gpg | sudo tee /usr/share/keyrings/oweecapture-archive-keyring.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/oweecapture-archive-keyring.gpg] https://oweeme.github.io/oweecapture stable main" | sudo tee /etc/apt/sources.list.d/oweecapture.list
sudo apt update && sudo apt install oweecapture

Actualizar más adelante:To update later:

sudo apt update && sudo apt upgrade

Fedora, Arch, openSUSE y otrasFedora, Arch, openSUSE and others

Descarga el código fuente y ejecuta el instalador. Se instala en tu carpeta personal y pide confirmación antes de usar sudo.Download the source and run the installer. It installs in your home folder and asks before using sudo.

tar xzf oweecapture-@VERSION@-fuente.tar.gz
cd oweecapture-@VERSION@
./install.sh --dependencias

Descargar el código fuenteDownload the source code · Fedora necesita RPM Fusion para H.264 y AAC. Para actualizar, descarga la versión nueva y vuelve a ejecutar ./install.sh.Fedora needs RPM Fusion for H.264 and AAC. To update, download the new version and run ./install.sh again.
